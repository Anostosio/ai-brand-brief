Конфиденциальность в Brand Brief Studio

Brand Brief Studio проектируется как статический local-only продукт. Содержимое анкеты обрабатывается на устройстве пользователя и не отправляется на backend Brand Brief Studio или внешнему AI-провайдеру.

Черновик миграции. Документ станет финальным только после проверки бесплатного production-хостинга, реальных данных оператора/контакта, настроек аналитики и применимых действий перед Роскомнадзором.

2. Анкета и созданный бриф

Анкета обрабатывается JavaScript-кодом в браузере пользователя. Нажатие «Собрать рабочий бриф» не отправляет поля анкеты на сервер Brand Brief Studio и не вызывает Groq, YandexGPT или другую удалённую модель.

Результат создаётся детерминированным evidence-aware алгоритмом, который поставляется вместе с сайтом. Он использует только введённые поля, отмечает гипотезы и зоны для проверки и не выдаёт результат за проведённое исследование рынка.

3. Локальное хранение в браузере

Черновик анкеты и недавние брифы хранятся через Local Storage браузера. Сохраняется до восьми последних брифов для каждого языка интерфейса. Запись истории может содержать исходные вводные, результат, evidence-метаданные, альтернативные направления и локальные временные метки.

У Brand Brief Studio нет пользовательского аккаунта и собственной application-базы, синхронизирующей эти записи. Они остаются на текущем устройстве/в текущем браузере до удаления пользователем, очистки данных сайта или удаления самим браузером.

Действие «Удалить локальные данные» удаляет ключи черновика и истории Brand Brief Studio из текущего браузера. Экспортированные JSON/PDF-файлы, сохранённые отдельно, сайт не контролирует.

4. Статический хостинг и технические данные

Целевая версия размещается как бесплатный статический сайт. Доставка любого сайта неизбежно раскрывает инфраструктуре хостинга обычные технические сведения запроса: IP-адрес, заголовки и временные метки. При этом у Brand Brief Studio нет application-backend, который получает содержимое анкеты, и нет product-level rate limiting по IP.

5. Яндекс Метрика

Яндекс Метрика необязательна. Её тег загружается только после выбора «Разрешить аналитику». При отказе приложение выставляет флаг отключения счётчика и не инициализирует Метрику.

Вебвизор отключён. Анкета не должна намеренно записываться через session replay. Выбор можно изменить через «Настройки аналитики». При отзыве приложение блокирует дальнейшую работу счётчика и по возможности удаляет доступные JavaScript first-party cookies и browser-storage идентификаторы Метрики.

Отзыв действует на будущую аналитику и не может задним числом удалить уже переданные события. В финальной документации оператора должна быть зафиксирована фактическая конфигурация счётчика, включая advanced/contact-data tracking.

7. Внешние сервисы

В целевом пути анкеты нет внешнего AI-провайдера. Google Fonts удаляется из runtime; до добавления локальных лицензированных файлов используются локальные/системные шрифты. Ссылка на портфолио открывается только после клика. Яндекс Метрика остаётся единственной необязательной аналитической зависимостью и загружается только после согласия.

8. Выбор пользователя

Конструктором брифа можно пользоваться без включения аналитики. Локально сохранённые данные продукта можно удалить через интерфейс или полностью очистить данные сайта средствами браузера.

Запросы субъекта персональных данных, относящиеся к инфраструктуре или необязательной аналитике, будут обрабатываться оператором по контакту из раздела 1 после заполнения сведений фактического оператора.

9. Статус production

Эта страница описывает целевую бесплатную local-only архитектуру в migration-ветке. Ею нельзя описывать старый production Vercel/Groq до завершения статического cutover. Перед публикацией проверяются хостинг, публичный URL, сетевой trace, настройки аналитики и документы оператора.
